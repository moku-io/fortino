Fortino is an open-source SSL VPN client for FortiGate gateways.

This installs:

  • the Fortino menu-bar app in Applications,
  • the fortinod VPN service, which runs as root and is started by launchd,
  • the fortino command-line tool in /usr/local/bin.

The user installing Fortino is allowed to use the VPN. Other users can be added in /Library/Application Support/Fortino/fortinod.toml.

To remove it: sudo /usr/local/libexec/fortino/uninstall.sh
