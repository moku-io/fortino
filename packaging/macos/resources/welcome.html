Fortino is an open-source SSL VPN client for FortiGate gateways.

This installs Fortino in Applications and the fortino command-line tool. Fortino opens when the installation finishes: allow its VPN service when macOS asks, or later in System Settings > General > Login Items.

Every user of this Mac can use the VPN, and each sees only their own profiles.

To remove Fortino, move it from Applications to the Trash.
